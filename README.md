# Skill Manager

Локальное приложение: выбираете проект, открытый в VS Code, отмечаете скиллы Claude Code
по категориям и одной кнопкой ставите их в `<проект>/.claude/skills/`.

## Установка

1. Запустите `Skill Manager Setup <версия>.exe`. Установщик ставит приложение только для вас
   (в `%LOCALAPPDATA%\Programs\Skill Manager`, без прав администратора) и создаёт ярлыки
   на рабочем столе и в меню «Пуск».
2. Установщик не подписан, поэтому при первом запуске Windows SmartScreen покажет
   «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

Node.js и Edge для установленного приложения не нужны; git в `PATH` нужен только для скиллов
из репозиториев. Закрытие окна полностью завершает приложение. Повторный запуск ярлыка
не открывает второе окно, а показывает уже открытое.

### Где лежат данные установленного приложения

| Что | Где |
|---|---|
| Мои скиллы, настройки, корзина | `%APPDATA%\Skill Manager\user\` |
| Клоны git-источников | `%APPDATA%\Skill Manager\cache\` |
| Журнал сервера (при ошибке запуска) | `%APPDATA%\Skill Manager\logs\server.log` |
| Базовый каталог | `<папка установки>\resources\catalog\` (обновляется новой версией) |

Удаление или переустановка приложения папку `%APPDATA%\Skill Manager` не трогает.

### Сборка установщика

```powershell
npm install
npm run dist
```

Готовый установщик — `dist\Skill Manager Setup <версия>.exe`, распакованная версия —
`dist\win-unpacked\Skill Manager.exe`. `npm run electron:dev` собирает приложение
и открывает его в Electron без установщика (данные — в `user/` и `.cache/` репозитория).

Иконка: исходник `build/icon.html`; после изменения выполните `node scripts/make-icon.mjs`
(нужен Microsoft Edge), чтобы пересобрать `build/icon.png` и `build/icon.ico`.

## Запуск из исходников (без установщика)

Нужны Windows 10 или 11, Node.js 24 или новее, git в `PATH` и Microsoft Edge
(приложение открывается в его окне).

```powershell
npm install
npm run app
```

`npm run app` при первом запуске собирает приложение и открывает его в отдельном окне.

- Разработка: `npm run dev` → http://127.0.0.1:4317
- Тесты: `npm test`

**Как остановить:** закройте окно терминала, в котором запущен `npm run app`, или нажмите в нём `Ctrl+C`.
Закрытие окна Edge сервер не останавливает.

**Если папка приложения лежит в OneDrive:** OneDrive синхронизирует `.cache/`, `.next/` и `node_modules/`
и может временно блокировать файлы в них (ошибки `EPERM`/`EBUSY` при сборке или обновлении каталога).
Исключите эти папки из синхронизации или держите приложение вне OneDrive (например, `C:\Apps\skill-manager`).

## Каталог скиллов

| Слой | Файл | Кто меняет |
|---|---|---|
| Базовый | `catalog/catalog.json` | автор приложения, приходит с обновлениями |
| Мой | `user/user-catalog.json` | вы, через «Мои скиллы → Добавить скилл» |

Свой скилл с тем же `id`, что у базового, перекрывает базовый.
Ниже `user/` — это папка `user/` репозитория при запуске из исходников
или `%APPDATA%\Skill Manager\user\` в установленном приложении.

**Как удалить сломанный свой скилл:** откройте `user/user-catalog.json` в редакторе, удалите запись
скилла из `skills` (и, если он больше не нужен, его источник из `sources`), сохраните файл
и обновите страницу приложения (`Ctrl+R`).
Формат манифеста — в [спецификации](docs/superpowers/specs/2026-10-18-skill-manager-mvp-design.md), раздел 4.

## ⚠️ Переустановка

При запуске из исходников папки `user/` (ваши скиллы и настройки) и `.cache/` (клоны репозиториев) — в `.gitignore`:
`git pull` их не трогает. Если удаляете папку приложения целиком — сохраните `user/`.

## После установки скиллов

Скиллы подхватываются автоматически. Если папки со скиллами раньше не было —
выполните `/reload-skills` в Claude или перезапустите Codex.

## Агенты и области

Скиллы ставятся в одну из четырёх папок — в зависимости от области (проект или «🌐 Глобально») и агента:

| Область | Агент | Папка |
|---|---|---|
| Проект | Claude | `<проект>/.claude/skills` |
| Проект | Codex | `<проект>/.agents/skills` |
| Глобально | Claude | `~/.claude/skills` |
| Глобально | Codex | `~/.agents/skills` |

Плитка «🌐 Глобально» ставит скиллы для всех проектов сразу.

### Категория «✓ Установлено»

Показывает всё, что лежит в папках выбранной области.

- Удалить (🗑) можно любую папку с `SKILL.md` в папке скиллов агента — не только
  скиллы, установленные приложением.
- Только для просмотра (🔒): скиллы, синхронизированные с claude.ai, скиллы плагинов
  (управляются через `/plugin`) и системные скиллы Codex.
- Устаревший скилл (↻) можно обновить до версии из каталога — только для того агента,
  к которому относится плитка.

### Корзина

Удалённый скилл переносится в корзину приложения `user/trash/`. Его можно вернуть кнопкой
«Вернуть» в уведомлении; записи старше 30 дней удаляются автоматически.

«Обновить» тоже не удаляет установленную копию безвозвратно: предыдущая версия переносится
в корзину `user/trash/`.

### Откуда берутся проекты

Только чтение, ничего из этого приложение не изменяет:

- VS Code — `storage.json`
- Claude Code — `~/.claude/sessions` и `~/.claude.json`
- Codex — `~/.codex/state_*.sqlite`
