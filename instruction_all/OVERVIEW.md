# Инструкции по вёрстке (plain HTML/CSS/JS)

Проект — статичный многостраничный сайт без сборщиков. Работа ведётся напрямую с файлами, без разделения на src/dist.

---

> ## Правило для AI-агента
>
> **При любом запросе на доработку проекта** («приведи по инструкции», «исправь», «доработай», «проверь соответствие», «пройдись по инструкции» и любые похожие) — агент обязан **сначала прочитать весь чеклист аудита ниже** и выполнить каждый пункт.
>
> **Не пропускать интерактивные блоки.** Слайдеры, попапы, галереи, бургеры, дропдауны — всё проверяется и при несоответствии **переписывается**. Частичное выполнение (только структура или только именование) — нарушение инструкции.

## Аудит существующего проекта

Если в проекте есть эти инструкции и получен **любой** запрос на доработку или проверку — агент выполняет **полный** аудит. Пропускать пункты нельзя. Выполнить нужно **всё** из списка ниже, а не только то, о чём явно попросил пользователь.

### Чеклист аудита

- [ ] **Структура** — привести к схеме из [00-project-structure.md](00-project-structure.md): создать недостающие папки, переместить файлы, удалить пустые нестандартные папки
- [ ] **Базовые стили** — проверить наличие в `css/main.css` секций СБРОС и ГЛОБАЛЬНЫЕ СТИЛИ с обязательным содержимым из [03-css.md](03-css.md); при отсутствии — добавить
- [ ] **Слайдеры** ⚠️ — **найти все слайдеры в проекте**; любой не на Swiper — переписать на Swiper целиком (HTML + JS + CSS). Не пропускать ни один.
- [ ] **Попапы и галереи** ⚠️ — **найти все попапы и лайтбоксы**; любой не через Fancybox — заменить на Fancybox целиком. Не пропускать ни один.
- [ ] **Табы** — ручную реализацию табов переписать на Swiper Thumbs
- [ ] **Интерактивные блоки** (бургер, дропдаун, аккордеон) — если используют `display: none/block` или jQuery — переписать на CSS `transition` + JS-классы
- [ ] **Библиотеки** — CDN убрать, скачать локально в `lib/`; сторонние библиотеки (не слайдеры/попапы) не удалять без проверки необходимости
- [ ] **CSS** — привести структуру `main.css` к порядку из [03-css.md](03-css.md); медиазапросы из `main.css` перенести в `media.css`
- [ ] **JavaScript** — привести структуру `main.js` к порядку из [04-javascript.md](04-javascript.md); каждый блок в IIFE
- [ ] **Именование** — привести файлы и классы к соглашениям из [08-naming-conventions.md](08-naming-conventions.md)
- [ ] **HTML** — обновить все пути после перемещения файлов; подключение CSS и JS — в правильном порядке
