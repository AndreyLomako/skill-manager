# Изображения

## Форматы

| Формат | Применение |
|--------|-----------|
| SVG | Иконки, логотипы, простая векторная графика |
| JPG / PNG / WebP | Фото, иллюстрации, сложная графика — используем тот формат, что предоставлен в макете |
| GIF | Только анимации — крайний случай |

## Как вставлять изображения

Все растровые изображения вставляем через обычный `<img>`. Тег `<picture>` не используем.

SVG-иконки вставляем:
- Через `<img>` — если иконка статичная и не требует стилизации через CSS
- Inline (вставить SVG-код в HTML) — если нужно управлять цветом через CSS (`fill`, `stroke`)

```html
<!-- Растровое изображение -->
<img src="img/main/hero.jpg" alt="Описание изображения">

<!-- SVG через img — нет необходимости менять цвет -->
<img src="img/icon/arrow.svg" alt="Стрелка">

<!-- SVG inline — нужно управлять цветом через CSS -->
<svg width="24" height="24" viewBox="0 0 24 24" fill="none" xmlns="http://www.w3.org/2000/svg">
  <path d="..." fill="currentColor"/>
</svg>
```

## Атрибут alt

`alt` — обязателен у всех `<img>`:

- Информативное изображение: `alt="Краткое описание что на картинке"`
- Декоративное изображение: `alt=""` (пустое — скринридеры игнорируют)

```html
<!-- Информативное -->
<img src="img/catalog/product.webp" alt="Кресло Comfort Pro серого цвета">

<!-- Декоративное -->
<img src="img/main/bg-decor.png" alt="">
```

Пустой `alt=""` используем **только** для декоративных изображений без смыслового содержания.

## Видео

Для всех тегов `<video>` обязательно добавляем атрибут `playsinline` — без него видео на iOS открывается в полноэкранном плеере вместо воспроизведения inline:

```html
<video src="video/promo.mp4" autoplay muted loop playsinline></video>
```

## Структура папок

Папки повторяют разделы сайта:

```
img/
├── main/       # изображения главной страницы
├── header/     # логотип, иконки шапки
├── footer/     # логотип и иконки подвала
├── form/       # иллюстрации в формах
├── icon/       # общие иконки
├── burger/     # иконки бургер-меню
└── other-page/ # изображения второстепенных страниц
```

Для каждой новой страницы при необходимости создаём отдельную папку.
